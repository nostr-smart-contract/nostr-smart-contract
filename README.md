# Nostr Smart Contract

This repository hosts a suite of smart contract tools built on the Nostr protocol, leveraging Bitcoin Script and the Lightning Network to enable decentralized, censorship-resistant applications.

---

## ⚠️ Archive Notice

This project is no longer actively maintained. It is archived for historical reference and may not receive updates or support.

---

## 📦 Overview

The Nostr Smart Contract project integrates Bitcoin Script and the Lightning Network with the Nostr protocol to facilitate decentralized smart contracts. It provides a foundation for building applications that require secure, trustless interactions without relying on centralized authorities.

---

## 🛠️ Features

* **Bitcoin Script Integration**: Utilizes Bitcoin Script to enable programmable transactions on the Bitcoin network.
* **Lightning Network Support**: Incorporates the Lightning Network for fast and low-cost transactions.
* **Nostr Protocol Compatibility**: Ensures seamless interaction with the Nostr decentralized network.
* **Smart Contract Suite**: Offers a collection of tools and libraries to develop and deploy smart contracts.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/nostr-smart-contract/nostr-smart-contract.git
   cd nostr-smart-contract
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Access the application at [http://localhost:3000](http://localhost:3000).
